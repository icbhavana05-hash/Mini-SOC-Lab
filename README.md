# Mini SOC Lab using Suricata IDS and Splunk SIEM

## Project Overview

This project demonstrates the implementation of a Mini Security Operations Center (SOC) using Suricata IDS and Splunk SIEM. The objective is to simulate real-world cyber attacks from Kali Linux against a Metasploitable 2 victim while Ubuntu monitors, detects, and visualizes the attacks.

The project showcases attack simulation, intrusion detection, centralized log collection, and dashboard visualization.



## Objectives

- Build a Mini SOC Lab
- Deploy Suricata IDS
- Configure Splunk Enterprise
- Simulate attacks using Nmap and Metasploit
- Detect malicious activities
- Visualize security events using dashboards



## Architecture

Kali Linux (Attacker)
        │
        ▼
Ubuntu Server
(Suricata IDS + Splunk SIEM)
        │
        ▼
Metasploitable 2 (Victim)
